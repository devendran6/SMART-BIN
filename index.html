Multi-Location IoT & LoRaWAN Architecture

How multiple outdoor dustbins transmit data across city-wide distances

1. Long-Range Wireless Transmission (LoRaWAN & NB-IoT)

Outdoor dustbins across different streets/campuses use LoRaWAN (868 / 915 MHz) transceivers. A single gateway covers a 10–15 km radius with minimal battery draw (3-5 years on battery or small solar cap).

2. Real-Time Packet Protocol (JSON / MQTT)

{
  "binId": "BIN-101",
  "location": { "lat": 12.9820, "lng": 77.5880 },
  "compostableFill": 88,
  "decomposableFill": 42,
  "batteryPercent": 94,
  "temperatureC": 41.2
}

3. Dynamic Route Optimization Algorithm (TSP)

The municipal server filters for bins with fill ≥ 75%, calculates the Traveling Salesperson Problem (TSP) shortest path from the central Bio-Plant depot, and dispatches the optimal GPS turn-by-turn route to the driver's tablet.
